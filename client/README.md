# Sustain Home Store

A full-stack MERN e-commerce application with:
- User auth
- Products listing with filtering and sorting
- Shopping cart + checkout
- PayPal integration (simulated)
- Admin dashboard for products, customers, purchases

## Technologies

MongoDB, Express, React, Node.js

## How to run

1. Backend: `npm install` + `npm start`
2. Frontend: `npm install` + `npx nodemon server.js`
